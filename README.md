# Agenda del Gerente v2

Marcador diario + pipeline de desembolsos por etapas (Por enviar → En mesa → Por firmar → Desembolsado / Rechazado).
Archivo único `index.html`, datos en el celular (localStorage, prefijo `gerente2:`), envío a GP por el mismo buzón de Apps Script con `formato: agenda-gerente-v2`.
